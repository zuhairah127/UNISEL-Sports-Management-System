# UNISEL Sports Management System

The UNISEL Sports Management System is a web-based platform designed to provide students with a centralized and convenient way to access sports-related services and activities.

The system allows users to explore UNISEL sports clubs, join clubs, book sports equipment, manage their profiles, participate in club groups, and communicate with administrators through a single platform.

## Link Website: https://4241000641.wixsite.com/unisel-sports-manage

## Key Features

- User registration and login
- User profile and account management
- Sports club information and overview
- Online sports club registration
- Sports equipment booking
- Booking status and management
- Club groups and community feed
- User notifications and notification settings
- Live chat with administrators
- Contact and social media information
- Admin dashboard
- User submission management
- Group and member management
- Equipment booking management

## Sports Clubs

The platform provides access to several UNISEL sports clubs, including:

- Archery
- Sepak Takraw
- Futsal
- Netball
- Basketball
- Rugby
- E-Sports

Users can view information about each club and submit a registration form to join their preferred sports club.

## Equipment Booking

The system provides an equipment booking feature that allows users to select available sports equipment and choose their preferred booking date and time.

Equipment booking is integrated with SimplyBook.me, where users can submit booking requests and view their booking status.

Available equipment categories include:

- Netball
- Futsal
- Sepak Takraw
- Archery
- Basketball
- Badminton

## User Features

Registered users can:

- Update personal information
- Upload or change profile pictures
- Create a public profile
- Manage notification preferences
- View notifications
- View joined sports groups
- Explore available groups
- Join club communities
- Create and share posts in club feeds

## Admin Features

Administrators can:

- Receive user registration and booking notifications
- View club registration submissions
- Manage sports groups
- Create new groups
- Add members to groups
- Communicate with users
- Manage sports equipment bookings
- Approve or cancel booking requests
- Configure equipment availability

## Live Chat

The platform includes a live chat feature that allows users to communicate directly with administrators for inquiries and assistance.

Administrators can respond to users through the dashboard or email.

## Platform and Tools

- Wix
- SimplyBook.me
- Wix Member Accounts
- Wix Groups
- Wix Forms
- Wix Live Chat

## User Interface

The website uses a black, white, grey, and orange colour scheme to create a modern and energetic sports-themed interface.

Anton is used as the main font to provide a bold and dynamic appearance while maintaining readability throughout the website.

## Project Purpose

The purpose of this project is to provide a centralized digital platform that makes sports activities and services more accessible to UNISEL students.

By combining sports club information, club registration, equipment booking, communication, and community features, the system provides a more organized and convenient way for students to participate in university sports activities.
